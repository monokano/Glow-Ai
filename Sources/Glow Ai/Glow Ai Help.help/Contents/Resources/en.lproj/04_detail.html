Detail Window

The Detail Window lets you inspect the version detection data used for a file, and re-run detection with different settings.

How to Open

Click "More Info" in the top-right corner of the Notification Window. The Detail Window appears as a sheet attached to the Notification Window.

Detail Information List

Shows all version-related data read from inside the file. Rows that contributed to the creation or compatibility version determination are shown in bold.

If the detected file type does not match the file extension, the "Kind" row is shown in red.

For an EPS file that was created by neither Illustrator nor Photoshop (for example by Ghostscript, CorelDRAW, Acrobat, or InDesign), the "Kind" row shows the producer along with the type, like "EPS format - 〔producer〕 (.eps)". If the producer cannot be read, "Unknown producer" is shown instead. These EPS files are always shown in red regardless of their extension.

Re-detecting the Version

Change any of the settings below and click "Detect" to re-run version detection with those settings. The result is also reflected in the Notification Window.

Detect Without Time Limit

Runs detection without a time limit, even when the time limit option is enabled. Use this when detection ended with a timeout.

Settings

Do not detect XMP: CreatorTool

Glow Ai does not use CreatorTool for version determination. This option is always on by default. Turn it off only when you want to check the CreatorTool value.

Do not detect EPS compatibility version (v9 and later)

The initial state reflects the Preferences setting. Turn it off when you want to check the EPS compatibility version.

Limit read size

The initial state reflects the Preferences setting.

Note Changes made in the Detail Window are not saved to Preferences. Settings reset each time the Notification Window is shown.

Closing

Click "Close" to dismiss the Detail Window and return to the Notification Window.
