Glow Ai Help

Glow Ai reads the version information embedded inside Adobe Illustrator files (.ai / .ait / .eps) and automatically opens them with the matching version of Illustrator. If an EPS file was created in Photoshop, Glow Ai displays the Notification Window so you can choose which version of Photoshop to open it with.
