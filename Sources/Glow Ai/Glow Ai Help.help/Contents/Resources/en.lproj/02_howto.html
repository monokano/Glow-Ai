How to Use

Opening a File

Method 1: Double-Click (Recommended)

Once .ai / .ait / .eps files are associated with Glow Ai (see how to associate files), simply double-clicking a file launches Glow Ai, detects the version, and opens the file with the appropriate Illustrator.

  1. Double-click a .ai / .ait / .eps file.
  2. Glow Ai launches and detects the file's version.
  3. If a matching Illustrator is found, the file opens automatically. Otherwise, the Notification Window appears.
Tip If double-clicking does not launch Glow Ai, the files are not associated with Glow Ai. See how to associate files.

Method 2: Drop onto the Dock Icon

  1. Drag and drop a file onto the Glow Ai icon in the Dock.
  2. Glow Ai detects the version and launches the matching Illustrator automatically.
  3. If no matching version is found, or if manual selection is required, the Notification Window appears.

Method 3: Open from the Menu

  1. Choose File > Open… (⌘O) from the menu bar.
  2. Select one or more files in the file chooser dialog.

Associating Files for Double-Clicking

Glow Ai does not change file associations automatically. To use Glow Ai by double-clicking, associate .ai / .ait / .eps files with Glow Ai.

You can do this with Associate in Preferences (see File association).

If the association does not change from Preferences, associate the files in the Finder as follows.

  1. Select a .ai file in the Finder and choose File > Get Info.
  2. In Open with, choose Glow Ai.
  3. Click Change All…, then click Continue in the confirmation message.
  4. Repeat these steps for a .ait file and a .eps file.

To undo this, choose Adobe Illustrator in Preferences and click Associate, or follow the same steps and choose Illustrator.

Processing Multiple Files at Once

You can open multiple files at the same time. Glow Ai processes them one by one. If the Notification Window appears, each window is shown in sequence — the next window appears after you close the current one.

Holding ⌘ While Opening

Normally, when a matching Illustrator version is found, the file opens automatically. Holding ⌘ (Command) while opening a file forces the Notification Window to appear, even when a matching version exists.

Glow Ai Quits Automatically

After handing the file off to Illustrator, Glow Ai quits on its own. There is no need to quit Glow Ai manually while working in Illustrator.

Tip Use the "Quit" button in the Notification Window to quit the currently running Illustrator directly from Glow Ai.

Importing Illustrator Icons

Files associated with Glow Ai are shown with the icons inside Glow Ai. To use the latest Illustrator icons, click Import Icons in Preferences (see File icons). Glow Ai does not import icons automatically on launch.

After you update Illustrator, import the icons again.
