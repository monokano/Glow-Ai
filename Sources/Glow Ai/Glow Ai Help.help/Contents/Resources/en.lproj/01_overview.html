About Glow Ai

What Glow Ai Does

Opening an Illustrator file with a different version of the app can cause layout shifts or lost features. Glow Ai reads the creation version recorded inside each file and automatically selects the matching version of Illustrator to open it with.

Glow Ai is especially useful when multiple versions of Illustrator are installed on your Mac.

Supported File Formats

Adobe Illustrator Document (.ai)
Standard Illustrator native format.
Adobe Illustrator Template (.ait)
Illustrator template format.
EPS File (.eps)
Because the file extension alone cannot identify the creating application, Glow Ai inspects the file content to determine it. If the EPS was created in Photoshop, the Notification Window appears so you can choose which version of Photoshop to open it with.
PDF File (.pdf)
Supports detection of PDFs that retain Illustrator editing capabilities. The Notification Window is always shown for these files.
Note Glow Ai determines file type from the binary content of the file, not the file extension. Disguised files (e.g., an AI file saved with a .pdf extension) are correctly identified.
