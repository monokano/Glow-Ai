Preferences

Open Preferences from the menu bar: Glow Ai > Preferences… (⌘,).

Always show Notification Window

When enabled, the Notification Window always appears — even when a perfectly matching version of Illustrator is found — so you can choose the app manually every time.

Default: Off (opens automatically when a matching version is found)

Tip To show the Notification Window just once without changing this setting, hold ⌘ (Command) while opening the file.

Associate file types on launch (.ai / .ait / .eps)

Default: On

When on: Every time Glow Ai launches, it re-registers itself as the default app for .ai / .ait / .eps files. Double-clicking those files will launch Glow Ai. If another app changes the association, Glow Ai automatically reclaims it on the next launch.

When turned off: At the moment you turn it off, the association is changed to the highest installed version of Illustrator (including Beta and Prerelease). Double-clicking those files will launch that Illustrator directly, bypassing Glow Ai. Use this setting when you want to restore the normal Illustrator file association without going through Glow Ai.

Tip If double-clicking no longer launches Glow Ai, check whether this option has been turned off. Turning it back on immediately re-associates the file types with Glow Ai.

Do not notify about file icon import

When on, the completion message shown after importing Illustrator file icons on launch is suppressed. The icon import itself still takes place as usual.

The guidance shown when an import cannot be completed (such as “Please move Glow Ai to the Applications folder”) is displayed regardless of this setting.

Default: off (notify on import)

Do not detect EPS compatibility version (v9 and later)

When enabled, Glow Ai skips the compatibility version detection step when processing EPS files. Compatibility version detection can take longer for larger EPS files.

Default: On (compatibility version is not detected)

Limit read size

Sets a maximum read size using the slider. When enabled, Glow Ai stops reading after the specified number of megabytes.

This is primarily intended to stop EPS compatibility version detection from taking too long on large files.

Default: On (5 MB limit)
