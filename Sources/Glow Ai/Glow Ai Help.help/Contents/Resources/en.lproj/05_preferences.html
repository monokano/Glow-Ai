Preferences

Open Preferences from the menu bar: Glow Ai > Preferences… (⌘,).

Always show Notification Window

When enabled, the Notification Window always appears — even when a perfectly matching version of Illustrator is found — so you can choose the app manually every time.

Default: Off (opens automatically when a matching version is found)

Tip To show the Notification Window just once without changing this setting, hold ⌘ (Command) while opening the file.

Do not detect EPS compatibility version (v9 and later)

When enabled, Glow Ai skips the compatibility version detection step when processing EPS files. Compatibility version detection can take longer for larger EPS files.

Default: On (compatibility version is not detected)

Limit read time

Sets a time limit for reading a file, from 1 to 10 seconds, using the slider. When enabled, Glow Ai stops reading once the specified number of seconds has passed since it started reading the file.

This is primarily intended to stop EPS compatibility version detection from taking too long on large files. When reading is stopped, the Notification Window shows “Time limit reached”.

Default: On (5 seconds)

File association (.ai / .ait / .eps)

Choose the app that opens .ai / .ait / .eps files when you double-click them — Glow Ai or Adobe Illustrator — and click Associate. Illustrator here means the latest installed release version (Beta and Prerelease are excluded).

The app that is currently associated is marked “(current)”.

On macOS Tahoe 26.3 and earlier, clicking Associate changes the association right away.

On macOS Tahoe 26.4 and later, when you click Associate, macOS asks you to confirm the change for each document type.

  • If you choose to change to the selected app, the association changes.
  • If you choose to keep the current app, the association does not change, and the remaining document types are not asked about.

If the association does not change even though you did not choose to keep the current app, Glow Ai shows how to associate the files in the Finder (see Associating Files for Double-Clicking).

Glow Ai never changes file associations on its own.

File icons

Click Import Icons to copy the .ai / .ait / .eps icons from the latest installed release version of Illustrator into Glow Ai. Files associated with Glow Ai then also show the latest Illustrator icons.

When the icons in Glow Ai are the same as that Illustrator’s icons, “The icons in Glow Ai are up to date.” is shown. After you update Illustrator, import the icons again. Glow Ai does not import icons automatically on launch.

Import Icons is unavailable, and the reason is shown, in these cases:

  • You are using a non-administrator account and Glow Ai was installed by an administrator. Importing from an administrator account applies the icons for every account on that Mac.
  • Glow Ai is running directly from where it was unzipped, such as the Downloads folder. Move Glow Ai to the Applications folder and open it again.
  • The Illustrator icons cannot be found.
Note When Show icon preview is on in the Finder’s view options, file icons show a preview of the file’s contents. Turn off Show icon preview to show the Illustrator file icons.
