Notification Window

The Notification Window appears when no matching app version is found, or when the file requires manual review before opening.

File Information

Icon

Shows the icon of the dropped file. A warning badge may appear above the icon, and a kind badge may appear to its left.

Badge

Displays a warning message or file type label when needed.

Filename

The name of the dropped file.

Created

The Illustrator version that created the file, as read from the file's internal data, displayed as an app name.
Example: Illustrator 2024 (28.7.10)

Note The file and app versions are matched down to the "major.minor" level (e.g. 28.7); any differences in the third and later numbers are ignored.

Compat.

The compatibility version (the version specified in the save options). Shown in red when it is lower than the default. For PDFs that retain Illustrator editing capabilities, "← Invalid" is shown in red because the compatibility setting does not actually apply to that format.
Example: Illustrator 2020 (24.0)

App List

Lists all versions of Illustrator installed on your Mac. When an EPS file was created in Photoshop, Photoshop appears in the list instead.

Blue dot (●)
Indicates the app is currently running.
App name
The name of the installed app. Beta and Prerelease builds are always greyed out to prevent accidental use in production.

Opening a File from the List

Double-click a row to open the file with that version of Illustrator. Alternatively, select a row and click the "Open" button. Double-clicking a greyed-out row shows an "Open" menu item that lets you force-open the file.

Buttons

Open
Opens the file with the selected app.
Cancel
Closes the window without opening the file.
Quit
Quits the currently running Illustrator. The blue dot disappears once Illustrator has actually terminated.

Checkboxes

Allow opening with compatible version
When checked, the compatibility version of Illustrator becomes available for opening the file. When unchecked, the compatibility version row is greyed out.
Allow opening with a newer version
When checked, versions of Illustrator newer than the creation version become available. When unchecked, newer version rows are greyed out.
Tip Click "More Info" in the top-right corner to open the Detail Window, where you can inspect detailed version detection data.
